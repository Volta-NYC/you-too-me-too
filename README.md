# You Too Me Too Styling Boutique

A multi-page Next.js draft for a women-owned, Asian-owned fashion and styling boutique in Flushing, Queens.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```

Business facts are centralized in `src/lib/site.ts`. Research, source conflicts, and image provenance are documented in `research/RESEARCH.md`.
